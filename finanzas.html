🧑‍🏫 Consejo de Don Peso

💱 El dólar en los últimos días

📌 Si la línea sube, el peso se debilita
🫵 Para ti: Si el dólar está caro (>$19), evita comprar en Amazon USA. Si está barato (<$18), ¡aprovecha!

📈 ¿Qué tanto sube y baja?

📌 El área muestra el rango de precios
🫵 Para ti: Rango amplio = más riesgo. Rango pequeño = estabilidad.

📊 ¿Subió o bajó hoy?

📌 Barras verdes = subió, rojas = bajó
🫵 Para ti: Si ves muchas barras verdes, ¡buena señal para el peso!

🏦 Tasas: Banxico vs CETES

📌 Naranja = Banxico, Verde = CETES
🫵 Para ti: Si CETES paga más del 10%, ¡es buen momento para ahorrar!

📉 Inflación (precios)

📌 Sobre 4% = tu dinero pierde valor
🫵 Para ti: Si la inflación está alta, compra hoy lo que necesites. Si está baja, espera ofertas.

🛢️ Petróleo Brent

📌 Afecta el precio de la gasolina
🫵 Para ti: Petróleo arriba de $80 = gasolina más cara. Abajo de $70 = gasolina más barata.

💵 Reservas Internacionales

📌 El colchón de dólares de México
🫵 Para ti: Sobre $200 mil millones = México fuerte. Si baja, puede haber problemas.
🏦
CETES para principiantes
Desde $100 pesos. Es el ahorro más seguro de México. Dan hasta 11% anual. Solo necesitas tu CURP.
💳
Tarjetas de crédito
Nunca pagues el mínimo. Siempre pago total. Las tasas de interés están en 30-80% anual. ¡Es mucho!
🏠
Comprar casa
Las hipotecas están entre 9-12%. Si la tasa Banxico baja, las hipotecas se abaratan. Espera si puedes.
💰
Fondo de emergencia
Guarda 3-6 meses de gastos en CETES o cuenta de ahorro. Te salvará de imprevistos.
